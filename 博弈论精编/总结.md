# 第1章 博弈论入门
- 博弈四要素
  - 至少两个参与者
  - 利益
  - 策略：在博弈中，决策主体根据获得的信息和自己的判断，制定出一个行动方案，即策略
  - 信息
- 结局
  - 最坏情况：两败俱伤（负和博弈）
  - 零和博弈：一方有收益，另一方有损失，且收益+损失等于零
    - 特点：存在利益冲突。所以解决此类困境在于从根本上消除双方之间利益冲突
  - 理想结局：双赢。即合作
- 经济离不开博弈

# 第2章 纳什均衡
- 解释：多人参加的博弈中，每个人根据自身策略制定最优解。当没人会主动变更自己的策略时（会降低自己的收益），此时便达到“纳什均衡”
  - 特点：非合作性均衡博弈

# 第3章 囚徒博弈
- 亚当斯密的局限性：当个体间利益没有交集时，每个个体追求利益最大化，便会使集体得到最大化的利益
- 解题思路之一：将自身困境化作对方困境
- 现实意义：反垄断法宝（商家间的“囚徒困境”），鼓励竞争让消费者获利

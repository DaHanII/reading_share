# 第6章 第一关键指标的约束力
## 创业的秘诀之一：专注
- 在任意指定的时间里，有一个指标值得你关注胜过一切
- 增长引擎（见第五章）最好在特定时段只关注其中一个
- 上述内容总结为一个概念OMTM（第一关键指标）
- 启发：和LLM应用中的注意力很像

## 使用OMTM的理由
- OMTM会随着时间变化而变化
- 使用理由如下
  - 回答了现阶段最重要的问题
  - 促使你设立初始（区别创业失败的）底线
  - 关注整个公司层面的健康
  - 鼓励一种实验文化（开展开发->测量->认知循环）
- 案例：Solare只关注少数几个关键指标
  - 指标特性：简单、即时、可付诸行动、利于比较、体现根本性

## 设定底线
- 关注指标还不够用，还需要设定数字底线，用以回答达到多少才算成功
- 如何确定成功数字目标
  - 商业模式：某一指标必须达到多少才能使商业模式本身成立
  - 行业同行基准

# 第8章 商业模式1：电子商务
- 主营业务：让访客在其网店上买东西
- 初期模式由“简单”漏斗构成，但是现在已经不那么简单，原因在于
  - 搜索关键字重要性更强
  - 推荐引擎
  - A/B测试及后续区别对待来源不同的访客
  - 购买流程前置在站外，比如社交平台引流，商家难以追踪
- 改进点：长漏斗流程与定价
- 图解（略）
- 关注要点：
  - 明确自己应该关注忠诚度还是客户的获取
  - 站内/站外搜索
  - 尽管转化率、重复购买率很重要，但是最重要的是每客户收入
  - 关注现实世界问题：配送、库存、物流等

# 第9章 商业模式2：SaaS
- 商业特点：将其服务分层出售，不同月费提供功能不同
- 挑战：找寻层级和价格的最佳组合
- 获客方式：通过免费增值模式获取客户
- 假设案例
  - 背景：项目管理工具创业公司，允许用户免费试用产品但是超过3小时开始收费。提供4个层级服务：免费版、10项目版、100项目版、无限制版
  - 关键指标：
    - 注意力：网站吸引访客效果如何
    - 参与度：多少访客注册成为了免费版或者试用版用户
    - 粘性
    - 转化率
    - 每客户收入
    - 客户获取成本
    - 病毒性：客户邀请他人或向他人推荐公司产品的可能性以及所需时间
    - 追加销售：是什么促使客户支付更多费用，以及这种情况的发生频率
    - 系统正常运行时间和可靠性
    - 流失率：单位时间内流失的用户以及流失的付费客户人数
    - 终身价值
  - 客户生命周期描述：公司通过病毒式营销或付费营销获取了一位用户；该用户很有可能在初次尝试后继续使用这款产品，并最终为之付费，同时还可能邀请他人，或升级到更高版本；作为付费用户，他可能会遇到些令人不快的问题并最终弃用。
- 案例分析：Backupify对客户生命周期的探索
  - 要点总结：
    - 在开始关注各种复杂财务指标之前，先把营收做好。但注意不要忽视成本，因为发展的关键是盈利能力
    - 当付费引擎状态良好，客户获取成本只占客户终身价值的一小部分时，即可加大投入、开始扩张。低占比是付费投入得到了较好回报的积极信号
    - 大多数SaaS公司依靠云经常性收入获取收益
  - 数据分析启示：
    - “从真的有人在乎这件事吗？”发展到“公司具有可扩张性吗？”。当发现公司根本性缺陷且无法持续发展时，可以尝试找找新的市场而非推倒重来

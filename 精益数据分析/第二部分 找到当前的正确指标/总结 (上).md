# 第6章 第一关键指标的约束力
## 创业的秘诀之一：专注
- 在任意指定的时间里，有一个指标值得你关注胜过一切
- 增长引擎（见第五章）最好在特定时段只关注其中一个
- 上述内容总结为一个概念OMTM（第一关键指标）
- 启发：和LLM应用中的注意力很像

## 使用OMTM的理由
- OMTM会随着时间变化而变化
- 使用理由如下
  - 回答了现阶段最重要的问题
  - 促使你设立初始（区别创业失败的）底线
  - 关注整个公司层面的健康
  - 鼓励一种实验文化（开展开发->测量->认知循环）
- 案例：Solare只关注少数几个关键指标
  - 指标特性：简单、即时、可付诸行动、利于比较、体现根本性

## 设定底线
- 关注指标还不够用，还需要设定数字底线，用以回答达到多少才算成功
- 如何确定成功数字目标
  - 商业模式：某一指标必须达到多少才能使商业模式本身成立
  - 行业同行基准

- 主营业务：让访客在其网店上买东西

# 第9章 商业模式2：SaaS
- 商业特点：将其服务分层出售，不同月费提供功能不同
- 挑战：找寻层级和价格的最佳组合
- 获客方式：通过免费增值模式获取客户
- 假设案例
  - 背景：项目管理工具创业公司，允许用户免费试用产品但是超过3小时开始收费。提供4个层级服务：免费版、10项目版、100项目版、无限制版
  - 关键指标：
    - 注意力：网站吸引访客效果如何
    - 参与度：多少访客注册成为了免费版或者试用版用户
    - 粘性
    - 转化率
    - 每客户收入
    - 客户获取成本
    - 病毒性：客户邀请他人或向他人推荐公司产品的可能性以及所需时间
    - 追加销售：是什么促使客户支付更多费用，以及这种情况的发生频率
    - 系统正常运行时间和可靠性
    - 流失率：单位时间内流失的用户以及流失的付费客户人数
    - 终身价值
  - 客户生命周期描述：公司通过病毒式营销或付费营销获取了一位用户；该用户很有可能在初次尝试后继续使用这款产品，并最终为之付费，同时还可能邀请他人，或升级到更高版本；作为付费用户，他可能会遇到些令人不快的问题并最终弃用。
- 案例分析：Backupify对客户生命周期的探索
  - 要点总结：
    - 在开始关注各种复杂财务指标之前，先把营收做好。但注意不要忽视成本，因为发展的关键是盈利能力
    - 当付费引擎状态良好，客户获取成本只占客户终身价值的一小部分时，即可加大投入、开始扩张。低占比是付费投入得到了较好回报的积极信号
    - 大多数SaaS公司依靠云经常性收入获取收益
  - 数据分析启示：
    - “从真的有人在乎这件事吗？”发展到“公司具有可扩张性吗？”。当发现公司根本性缺陷且无法持续发展时，可以尝试找找新的市场而非推倒重来
## 指标详解
- 衡量参与度：日活跃量
  - 分析活跃量不仅要关注访问频率等原始数据，还要关注下用户的使用规律。这些规律一般靠两种方式得到
    - 将理想用户和非理想用户区分开来，并找出二者的不同
    - 判断某项产品改动是否奏效，可先测试部分用户的反映，然后进行测试组与对照组比对
- 流失率
  - 付费用户与非付费用户分开考量
  - 流失定义建议：近90天内没有登录过的用户视为非活跃用户
  - 公式计算：一段时间内流失的用户数/这段时间开始时的用户数
    - 容易受特定时间干扰，因此可以改进为：一段时间内流失的用户数/（（这段时间开始时的用户数+时间段结束时的用户数）/2）。此公式建议按天为单位计算得出
## 图说SaaS公司
- 案例分析：ClearFit放弃月费模式后获得了10倍增长
  - 启示：必须了解自己的客户，知道他们是谁，明确他们的购买方式和购买理由，以及他们是如何评价你的产品或服务的
  - SaaS不一定非要按照月费或者年费的模式。如果服务的存续性十分短暂，则可考虑按件计费。定价是一个棘手的问题，需要以定性和定量的方式来测试不同价位。不要以为低价一定会带来好的结果，客户可能会因此低估产品或服务的价格。记住，价格是产品或服务的一部分。
- 难题与挑战
  - 产品推广模式
    - 完全付费模式可有效控制成本，更具有预测性且能够即时明确所提供服务是否具有相应的价值
    - 免费增值模式则让你了解用户如何使用产品，并建立良好的信誉

# 第10章 商业模式3：免费移动应用
- 假设案例
  - 背景：游戏公司关注的指标如下：
    - 下载量
    - 客户获取成本
    - 应用运行率：有多少下载用户真正开启了该项应用，并注册了账号
    - 活跃用户/玩家比例
    - 付费用户率
    - 首次付费时间
    - 每用户月平均收入：购买收入和广告收入的总和，通常还包括特定于某个应用程序的信息，如哪个商品最吸引用户
    - 点评率
    - 病毒性：平均每位用户可以邀请多少新用户
    - 流失率：卸载应用或一定时间内没有开启过应用的用户比例
    - 客户终身价值
  - 指标介绍
    - 安装量：重要渠道应用商店推荐
    - 每用户平均收入
      - 方式一：应用总营收/活跃用户人数
      - 方式二：计算每位流失玩家的平均消费金额
    - 付费用户比例
      - 大部分收入来自于一小部分用户（“鲸鱼”玩家），应将该部分用户单独划归一组进行研究
      - 尽量追踪付费用户的平均收入。同时要注意到“鲸鱼”玩家和其他玩家的想法行为差异
    - 流失率

- 难题：应用内购买与广告
